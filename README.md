# 💧 RefillMap — Smart Campus Water Refill Directory

**Find water. Refill your bottle. Save the planet. 🌱**

RefillMap is a mobile-friendly campus water refill directory designed to help students and faculty quickly locate drinking water stations across campus. It provides station availability, water status, and issue reporting to encourage reusable bottles and reduce single-use plastic waste.

## 🚀 Project Status

🟢 **Phase 1: First Layout — Completed**

🔄 **Phase 2: Second Layout — In Progress**

The first layout has been successfully completed and is working. Development is now focused on the second layout, with improvements to the interface, features, and overall user experience.

## ✨ Key Features

- 💧 **Water Station Directory:** Find water coolers and RO refill points across campus.
- 📍 **Location-Based Discovery:** Identify nearby refill stations based on your selected building.
- 🟢 **Water Availability Status:** Check whether a station is working or under maintenance.
- ❄️ **Cold Water Availability:** Identify stations offering cold drinking water.
- 🚨 **Report an Issue:** Report problems such as low pressure or non-functional stations.
- 🔍 **Search & Filters:** Find stations using search and availability filters.
- 📱 **Responsive Design:** Access the directory on mobile devices and desktops.
- 🌱 **Sustainability:** Encourage reusable bottles and reduce plastic waste.
